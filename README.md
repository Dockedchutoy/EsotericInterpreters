# EsotericInterpreters
Interpreters of esolangs in Python unless noted otherwise.

All interpreters are made to be easily importable for no real reason except because i wanna.

## List of Esolangs
* 1 Bit, a Quarter Byte - It's just a more complicated adder (Nim)
* BRING BACK THE OLD SANDBOX - A "memorial" language (Nim)
* Deadfish - One of the more known joke esolangs with only four instructions (Python)
* Symbolic Brainfuck - Brainfuck extension using symbols (Python)
